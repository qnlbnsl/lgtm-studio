# The retired older page

Do not build a screen here, and do not change one here.

This package is the older web page of LGTM Studio.
The service stopped serving it on 2026-11-14.
The website is built by `packages/studio` from `design/mock/`, and the engine serves it at the root address.
The section "Where the website lives" in the root `AGENTS.md` says where screen work goes.

The tests and browser journeys in this package still run.
Many of them test the engine through the older page.
The package is removed once each journey has an equal journey on the website, as issue 875 in `docs/issues.md` records.
