SP-03 Sidebar and attention

Goal

The owner sees what needs an answer from any page. The sidebar folds to a rail when the owner wants the room.

What the owner sees

The sidebar folds to a rail 48 pixels wide. The rail keeps one icon for each repository.

A count beside a project says how many requests wait there. The counts add up to the number on the bell.

A filter shows only the projects that need the owner.

Opening a thread from the board

A task on the board opens its agent's thread. Where the thread opens is an open question for the owner.

Checks

The browser tests answer one request and see the project's count and the bell's count each drop by one.
