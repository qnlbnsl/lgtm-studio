SP-04 Narrow-screen pass

Goal

Every page can be used with the keyboard alone, and every page fits a phone 390 pixels wide.

What is reviewed

Two reviewers walk each page with the Tab key and write down every place where the order surprises them.

The same reviewers open each page at 390 pixels and write down every part that is cut or that scrolls sideways.

How findings are scored

A finding is scored from 0 to 10. A finding that stops a task is a blocker, and the sprint does not close while one is open.

Checks

Round 2 ends with no open blocker. The full test run passes on the merged branch.
