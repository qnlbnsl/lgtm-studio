SP-08 Search inside a thread

Goal

The owner finds one message in a long thread without scrolling. A search box in the thread's head line filters the thread to the messages that hold the words.

What the owner sees

Ctrl F in a thread opens the search box. Each match is marked in its message, and a count such as "3 of 12" sits beside the box. Enter goes to the next match, and Shift Enter goes to the one before.

Escape closes the box and returns the thread to where it was.

What is searched

Part of a messageSearched
The text of the owner and of the agentYes
The summary line of a tool runYes
The folded lines of a tool runOnly when the run is open
A question and its answersYes

Checks

A thread of 4,000 messages answers a search in under 100 milliseconds. The browser tests search for a word that sits in the first message and in the last one.
