| 9 | Which sessions does a credential change or removal end? | A change removes the stored web sessions together. Assume a failed cleanup is reported explicitly and that the operator retries removal with PostgreSQL available before restoring the former password. | The owner approved restart persistence and revocation on change or removal on 2026-11-25 in the foundation design. | 10 | How are the password and row binding represented? | Assume a password has 1 to 4096 UTF-8 bytes and is used exactly as supplied. Compare fixed digests in constant time. Use a 720-hour lifetime from database time. | The old engine supplies an input bound and a salted memory-hard binding. The 2026-11-25 design rules out import, so the Go code has its own byte layout and does not copy source. | unanswered | 2026-11-26 |
| 11 | Which origins and cookies does the transport accept? | Assume a configured public origin and an exact list of additional origins. Require HTTPS on both sides of a cross-site request.
