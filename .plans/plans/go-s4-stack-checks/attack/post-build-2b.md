## post-2b 1 (MAJOR) A malformed control can prevent valid arming

The plan requires the relay to reject a malformed control and bind holds to the intended stream. By reading, stream allocation uses `rand.Text()`, but control reconciliation checks only that `stream_id` is nonempty. The repair advances `lastGeneration` before returning for an absent stream. [Plan](../plan.md#L85) [Stream allocation](../../../../deploy/test/sprint4relay/main.go#L488) [Control validation](../../../../deploy/test/sprint4relay/main.go#L593) [Generation update](../../../../deploy/test/sprint4relay/main.go#L611)

Confirmed live in a scratch probe. A control containing a single space as its stream identifier and the maximum generation advanced the counter to that maximum. After an atomic replacement with the live stream’s identifier and generation 1, the event passed through. The runner would wait for `armed` and `held` records that cannot arrive in that relay process. Validate the identifier against the allocator’s format before advancing the counter, and test that a valid control still arms after a malformed one.

## post-2b 2 (MINOR) The tests accept a relay that drops the event-gap reason

The plan requires preserving refusal metadata. Foundation rule R8 and the link contract define an `event_gap` refusal for a numbered event above the next expected number. By reading, the implementation permits that reason, and the sole positive control in the new trailer matrix uses `link_revision_mismatch`. [Plan](../plan.md#L85) [Foundation rule R8](../../../../docs/specs/2026-11-25-go-rewrite-foundation-design.md#L369) [Link contract](../../../../src/contracts/proto/lgtm/link/v1/link.proto#L63) [Relay allowlist](../../../../deploy/test/sprint4relay/main.go#L435) [Trailer matrix](../../../../deploy/test/sprint4relay/review_test.go#L154)

Confirmed live by removing only `event_gap` from the allowlist in scratch. Every committed relay test passed, and the package printed `ok` in `0.707s`. A relay with that change would leave a downstream test seeing a status without the reason that identifies the gap. Add a positive case that sends a gap after authenticated Open and checks that exactly one `event_gap` reaches the downstream trailer.
