## post-2 1 (MAJOR) A control can arm a different stream

The plan requires a control to bind to one live stream and its generation to retire permanently when that stream closes. This protects the fresh replay required by foundation check C11. By reading, the relay assigns sequential stream identifiers from a counter initialized for each process. The generation high-water mark also starts over. When the control names a stream that does not exist yet, the relay leaves the file eligible for a later poll or frame. [Plan](../plan.md#L85) [Foundation check C11](../../../../docs/specs/2026-11-25-go-rewrite-foundation-design.md#L388) [Stream allocation](../../../../deploy/test/sprint4relay/main.go#L431) [Control reconciliation](../../../../deploy/test/sprint4relay/main.go#L528)

Confirmed live in two scratch probes. First, I armed an event, saw it held and discarded, and restarted the relay with the original control file. A Join followed by an Open for the same machine reused the old stream identifier and held the new event. Second, I published a control for the next identifier while only the old stream existed, completed a heartbeat on the old stream, and closed it. The relay armed the file when the next stream opened and held its event. Both scenarios used one live stream for the machine at a time. Give each stream an opaque identifier unique across relay starts and reject a control observed before its named stream is live. Cover both scenarios in the relay suite.

## post-2 2 (MAJOR) A response header can become a terminal refusal

The plan requires preserving refusal metadata. Foundation decision D7 requires key proof, and rule R8 requires a contract error. The link contract assigns streaming refusal reasons to the end of the stream. By reading, the relay falls back to merged error metadata when the upstream trailer is empty and copies an allowed reason into its downstream trailer. The client checks that trailer to decide whether to stop after a verified Challenge. [Plan](../plan.md#L85) [Foundation decisions](../../../../docs/specs/2026-11-25-go-rewrite-foundation-design.md#L32) [Foundation rule R8](../../../../docs/specs/2026-11-25-go-rewrite-foundation-design.md#L369) [Link contract](../../../../src/contracts/proto/lgtm/link/v1/link.proto#L51) [Relay fallback](../../../../deploy/test/sprint4relay/main.go#L366) [Client refusal handling](../../../../src/client/internal/link/conn.go#L207)

Confirmed live with a peer that sent a signed Challenge, a leading `link_revision_mismatch` header, and `failed_precondition` without a refusal trailer. The direct call had an empty trailer. The relayed call had a refusal trailer that would make a verified client stop retrying. Propagate a refusal reason only when the upstream trailer contains exactly one contractual reason. Add a header-only negative case alongside the existing trailer case.

## post-2 3 (MINOR) A malformed Join error echoes the submitted secret field

Foundation rules R8 and R9 require a public error sentence and keep secrets out of diagnostic output. By reading, the generated handler decodes the unary Join request before the relay's Join method can sanitize errors. Confirmed live with a synthetic malformed Join request. Hypertext Transfer Protocol (HTTP) returned status 400 and included the submitted `tokenSecret` value in the error text. The caller could retain that response as a diagnostic. Return a fixed error message for Join decode failures and assert that the submitted value is absent from the response. ## post-2 4 (MINOR) The relay drops errors when it writes closure evidence

The plan requires both discard records and the closure record before the runner starts the replacement. By reading, `closeStream` removes the stream and ignores the errors from each terminal write. Confirmed live with a writer that accepted an arm and hold, then failed at closure. The discard and close records were missing, and the error surfaced only when another record was attempted. If traffic stops after the old stream closes, the runner waits for records that will never arrive. Surface a fixed diagnostic and fail the relay when a required terminal observation cannot be written. ## post-2 5 (MINOR) The tests accept a relay that logs enrollment secrets

Foundation rule R9 requires secrets to stay out of logs. Confirmed live with a scratch mutation that added the hexadecimal Join token secret to the `forwarded` Join record. Every committed relay test still passed. The scratch audit of the actual observation file failed on the mutated relay. Add a test that inspects the full observation records and rejects unexpected fields and any fixture token, key, signature, or event payload.
