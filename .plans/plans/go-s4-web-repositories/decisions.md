## What the closing reviews assigned to the website

| Source line | What this plan does |
|---|---|
| Round-three logic, replace snapshots on reconnect, ignore superseded inspection replies, and locate both stop actions in the bare composer. | Items 3 and 6 cover the independent replacement snapshot and inspection schedule, including old successes and refusals. The composer is absent in sprint 4. Its two stop actions stay with the sprint 5 project and lead build. |
| Round-three fit, register the new services and migrations using authenticated streaming and preserve credit. | The result asks Projects for authenticated registration, browser preflight, and the generated watch and unary entry points. The website consumes the service after discovery. The sprint 5 service and server migrations belong to the server. Credit remains governed by `AGENTS.md`. |
| Round-three fit, join the add response to the repository watch by the returned identity and ignore replies after server or session changes. | Items 2, 3 and 6 combine a single lifetime fence with the repository and folder identifiers. Tests order the reply and watch both ways and check sign-out, expiry and server replacement. |
| Round-three fit, list empty or unavailable views, repository views, terminal shortcut and collapsed or wide lead column. | Items 4 and 9 cover both terminal entry points, the empty and saved routes, and the absence of lead and repository agent columns at both widths. |
| Round-three fit, keep the budgets visible in boundary fixtures and retain the older-items indicator. | Folder byte-budget enforcement and fixtures remain with the reviewed contract, Projects and Folders. The website passes exact typed paths and shows the fixed refusal. The browser's long-value fixture checks layout. The thread indicator belongs to sprint 5. |
| Closing lines for send permits, run replay, project rollback and lost replies, repository creation, adapter installation, lead scrolling and output ordering. | These belong to Link, Projects, Folders or sprint 5. The sprint 4 browser retains a reusable session lifetime and join so later watches can extend readiness and link a project to its repository and lead. |
