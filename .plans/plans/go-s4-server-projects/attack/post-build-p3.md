### post-p3 5 · MAJOR · R10 can fail when a valid result reaches the relay before its report

Confirmed live, the first unmodified host race run failed at the held-report watermark assertion. The diagnostic merges two conditions. It reports the same failure when the relay has yet to see the folder event and when it sees a different event number. The client gives queued results priority over sending buffered events, and the wire contract captures the durable event number at receipt completion. I reproduced the same assertion failure three times by delaying only the outgoing folder event by 400 milliseconds after durable append. A fourth run traced a result watermark of 3 and the delayed folder event numbered 3. An ordinary scheduling delay can therefore fail the release run before the test checks staging. Wait for the relay to hold the matching report and for the matching result to arrive. Compare the result watermark to the held report and use the result watermark for the staged-row assertion. Stop independent appends first if the fixture needs exact equality. This covers the paired plan and foundation rule 10. ### post-p3 6 · MINOR · R5 leaves the retry against an open operation unobserved

Confirmed live, returning unavailable only when a keyed retry reads an open operation passed the initial restart probe and three traced repetitions. Both retries read `succeeded` in every traced run. The fixture starts a retry in a goroutine, reads the already-existing operation from a separate connection, and releases the report after the client reconnects. That read establishes that the operation survived restart. It provides no evidence that the retry itself reached the open state. A retry that lands before the report commits can be refused by the broken program even though the test can pass when it lands later. Observe the retry reading the open operation before releasing the report. In a separate run, let the report commit and acknowledge before issuing the first retry to check that settlement proceeds without any waiting caller. This covers the paired plan and foundation rule 7.
