### architect-r1 01 — Bind a result to the command's machine, stream and attempt

### architect-r1 04 — Make the 30-second presence cutoff independent of the stream writer

**MAJOR · C8 · Bug (timing) · Confirmed by reading · Server presence and transport.** The handler selects on the heartbeat timer only after claiming and sending pending commands. ### architect-r1 05 — Bound feed references in bulk claims and connection cleanup

### architect-r1 06 — Keep every supported report and sequence representable in PostgreSQL

**MAJOR · C11 · Design · Confirmed by reading · Server inbox, with Contract for wire limits.** The contract uses `uint32` for cores and agent limit and `uint64` for memory bytes and sequence numbers.
